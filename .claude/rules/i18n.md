# The catalogs

Before changing a catalog, read `docs/spec/ui/pages.md`, Messages and Catalogs.

- `MessageKey` is derived from `en.json`, so a removed key fails type-check.
- `scripts/lib/i18n-check.ts` flags an unknown literal key and a key nothing names. A
  family of keys is a template literal that `t()`'s first argument can evaluate to (`pages.md`,
  Catalogs); a block's or an error's key goes through `blockKey` or `errorKey`.
- A Japanese text calls each term by its word in `src/i18n/glossary.json` (`pages.md`,
  Catalogs); a different word found in review joins the term's avoided words.
