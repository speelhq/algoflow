# The catalogs

Before you change a catalog, read `docs/spec/ui/pages.md`, Messages and
Catalogs.

- `MessageKey` is derived from `en.json`, so removing a key that code still
  uses fails the type check.
- `scripts/lib/i18n-check.ts` flags a literal key that doesn't exist and a
  key that nothing names. To name a family of keys, use a template literal
  that `t()`'s first argument can evaluate to, such as
  ``t(`problems.topic.${topic}`)`` (`pages.md`, Catalogs). Build a
  block's or an error's key with `blockKey` or `errorKey`.
- In a Japanese text, call each term by its word in
  `src/i18n/glossary.json` (`pages.md`, Catalogs). When review finds a
  different word for a term, add that word to the term's avoided words.
